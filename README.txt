WORD DETECTIVE v2
=================
이번 보완판은 기존 v1의 로컬 에셋/PWA 구조를 유지하면서 첨부된 진행본의 좋은 아이디어를 실제 로직으로 연결한 버전입니다.

핵심 보완
- 첫 실행 수사관 이름 등록 + 상단 프로필 + 캐릭터 대사창
- 1단계: 카드 2회 뒤집기 완료 전 다음 단어 이동 제한, 마지막 카드 후 2단계 자동 진입
- 카드 발음 듣기 + 브라우저 지원 시 직접 발음 인식
- 2단계: 전체 단어를 영어→한글/한글→영어 50:50 방식으로 진행
- 3연속 정답부터 FEVER, 실제 XP 2배 반영
- 3단계: 4쌍씩 모든 단어를 순차 매칭, 스톱워치, 틀린 타일 오답 누적
- 4단계: 단어 3초 노출 후 5글자 이하 2칸/6글자 이상 3칸 랜덤 마스킹
- 힌트: 상황 → 의미 → 빈칸 한 글자씩 집중 힌트
- 보스전도 전체 단어를 순차 완료해야 4단계 학습 완료
- 사진 추출 결과는 기존 시험지에 중복 없이 누적
- Gemini 구조화 JSON 출력(responseSchema) 적용
- API 키 하드코딩 제거
- 내 단어장: 오답/철자오답/복습 성공 2회 기준 유지
- 캘린더/XP/연속 학습 로컬 저장 유지
- 결과에서 모바일 공유창을 열어 카카오톡 등으로 제출 가능
- 외부 Tailwind/FontAwesome/Google Font/Kakao SDK 없이 로컬 UI 유지

배포
이 폴더의 파일 전체를 Netlify에 배포하세요.
index.html만 단독으로 올리면 PWA/이미지/서비스워커가 동작하지 않습니다.

AI 사진 추출
설정에서 본인의 Google AI API key를 입력해야 합니다.
키는 브라우저 LocalStorage에 저장됩니다.


v3 추가 보완

V4 UPDATE
---------
- 학습 미션 순서 자유화: 카드 / 4지선다 / 타일 연결 / CODE RED를 원하는 순서로 실행
- 각 미션 완료 후 다음 단계 강제 이동 제거, 미션 선택 화면으로 복귀
- 4지선다의 영어→한글 / 한글→영어 방향을 매 실행마다 랜덤 배정
- CODE RED를 아나그램/크립토그램 두 방식으로 구현하고 단어마다 랜덤 선택
- 같은 CODE RED 방식이 과도하게 연속될 가능성을 완화
- CODE RED 기억 시간: 총 2초 (첫 1초 선명, 다음 1초 점멸)
- CODE RED 방식 다시 뽑기 버튼 제공
- 오늘 완료한 미션은 체크 표시되며 다음 날 자동 초기화
