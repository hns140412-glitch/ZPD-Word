HIDE & SEEK — HIDDEN WORD TRAIL
===============================

현재 제품명: Hide & Seek
현재 마스터: Hide_Seek_UI_MASTER_LOGIC_REV_04.md
현재 세계관: 보물찾기 + 술래잡기 + 숨은 단어 탐험

핵심 흐름
- 시험지/단어 사진 촬영
- 셔터 즉시 임시 저장 후 다음 촬영
- OCR SEE / PAIR
- 저장 전 사용자 확인
- 단어/뜻 학습
- 약한 단어 우선 복습
- 마지막 철자 찾기
- 놓친 단어 다시 찾기

현재 사용자 경험 용어
- FIRST FIND
- MEANING CLUE
- CONNECTION TRAIL
- HIDDEN WORDS
- FINAL SEEK
- SEEK AGAIN

더 이상 현재 제품 세계관으로 사용하지 않는 표현
- 경찰
- 형사
- 수사
- 체포
- 검거
- 범인
- 사건
- 사건 파일
- 단어 체포

기존 저장 키나 내부 변수명에 과거 명칭이 남아 있을 수 있으나 데이터 호환용입니다. 사용자 UI와 현재 마스터 기준으로 사용하지 않습니다.

배포
이 폴더 전체를 Netlify 또는 정적 HTTPS 호스트에 배포합니다.
index.html만 단독 배포하면 PWA/이미지/서비스워커가 정상 동작하지 않습니다.

AI 사진 추출
공개 배포에서는 API 키를 클라이언트에 장기 저장하지 않고 서버 프록시를 사용하는 방향을 권장합니다.

검증
배포 완료만으로 Release PASS가 아닙니다. 실제 모바일에서 카메라/앨범/OCR/PWA 설치/오프라인/업데이트/터치 동작을 확인해야 합니다.
