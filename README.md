# Hide & Seek — Hidden Word Trail

Current product authority: `Hide_Seek_UI_MASTER_LOGIC_REV_04.md`

Hide & Seek is the current vocabulary discovery and retrieval PWA. The active child-facing world is **treasure-seek / hide-and-seek / hidden-word exploration**.

## Active world

- 숨은 단어를 찾는다
- 단서를 따라간다
- 놓친 단어는 다시 숨고 다시 찾는다
- 길잡이와 함께 탐험한다
- 성공은 단어를 발견하고 꺼내 쓰는 것이다

Detective/police/arrest/case framing is superseded and must not return to the current UI.

## Preserved learning core

- camera/photo worksheet intake
- rapid capture with immediate temporary save
- OCR SEE / PAIR
- review-before-commit
- bidirectional retrieval
- TTS / speaking support where available
- weak-word prioritization
- final spelling retrieval and targeted re-retrieval
- local persistence and PWA behavior

## Current child-facing learning path

`FIRST FIND → MEANING CLUE → CONNECTION TRAIL → HIDDEN WORDS → FINAL SEEK → SEEK AGAIN`

Legacy implementation identifiers may remain temporarily for migration compatibility only. They are not current product language.

## Validation boundary

Static/package validation and deployed state do not automatically equal Release PASS. Real mobile camera/photo permissions, OCR, install/offline/cache/update and touch behavior must be verified on actual devices.

## Naming lineage

Repository name and some internal storage keys may still contain historical names for compatibility. Current product name and current master authority are **Hide & Seek**.
